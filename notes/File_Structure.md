# ProjectClawNet File Structure Reference

## Root Directory Overview

- `README.md` – High-level project overview and onboarding steps.
- `package.json` / `package-lock.json` – Dependency manifests, npm scripts, audit tooling.
- `vite.config.js` – Vite build configuration (React plugin, path aliases if added).
- `tailwind.config.js` / `postcss.config.js` – Tailwind theme tokens and PostCSS pipeline.
- `eslint.config.js` / `.prettierrc.json` – Linting and formatting standards.
- `netlify.toml` & `vercel.json` – Hosting and deployment directives (security headers, redirects, build commands).
- `LICENSE` – MIT license declaration.
- `dist/` – Production build artifacts generated by Vite (`npm run build`).
- `public/` – Static assets copied verbatim to build output (robots, sitemap).
- `docs/` – Module-specific documentation (Auth, Community Grid, File Upload).
- `notes/` – Internal working notes (`Developer_Notes.md`, `Technical_Notes.md`, this structure reference).
- `supabase/` – SQL migrations provisioning schemas, RLS policies, seed data.
- `tools/` – Desktop tooling artifacts (ClawView app build output and static assets).
- `src/` – Application source code (React SPA, styles, contexts, utilities).
- `DEPLOYMENT.md`, `EMAIL_VERIFICATION_SETUP.md`, `FILE_UPLOAD_GUIDE.md`, `GITHUB_SETUP.md`, `SECURITY.md`, `SECURITY_IMPROVEMENTS.md`, `SEO_SETUP.md`, `FEATURE_UPDATES.md` – Operational and historical documentation set.

## Source (`src/`) Breakdown

### Entry Points & Global Setup

- `main.jsx` – Bootstraps React app, mounts `<App />`, registers Tailwind styles.
- `App.jsx` – Defines routing (`react-router-dom`), layout scaffolding, transition logic, terminal toggle, loader state.
- `index.css` – Tailwind directives (`@tailwind base/components/utilities`), global custom styles.
- `supabaseClient.js` – Supabase initialization (environment-driven, fail-fast on missing keys).

### Contexts & Hooks

- `contexts/AuthContext.jsx` – Supabase auth session management, sign-in/out/up helpers, context provider.
- `contexts/CyberChaosContext.jsx` – Thematic context (glitch/particle effects) for shared UI cues.
- `hooks/` – Reserved for custom hooks; currently empty (future extension point).

### Pages (`src/pages/`)

- `LandingPage.jsx` – Aggregates hero, product, community, stats sections; receives outlet context for auth transitions.
- `CommunityHubPage.jsx` – Post feed with search/filter, Supabase subscriptions for realtime updates.
- `TeamPage.jsx` – Presentation of team members and organizational roles.
- `AboutPage.jsx` – Storytelling layout covering PCTE origins, mentor council, mission.
- `CyberOperationsPage.jsx` – Service lineup overview with cards leading to detail view.
- `ServiceDetailPage.jsx` – Dynamic service detail route (`/services/:serviceId`) with methodology, deliverables, CTA.
- `ResearchPage.jsx` – Detailed view for research content / threat intel posts.
- `ToolDetailPage.jsx` – Deep dive per product (PortLock, ClawNet Core, ClawView) with downloads/snippets.
- `AdminDashboard.jsx` – Multi-tab admin console (Overview, Moderation, Users, Analytics, Settings) including charts, audit logs, service request workflow.

### Components (`src/components/`)

- `Navbar.jsx`, `Footer.jsx` – Primary navigation and site footer (feedback modal integration).
- `Hero.jsx`, `About.jsx`, `TeamPreview.jsx`, `Products.jsx`, `Blog.jsx`, `Stats.jsx` – Home page building blocks.
- `Products/` – Animated demos and download CTA:
  - `ClawNetCoreDemo.jsx`, `ClawViewDemo.jsx`, `PortlockDemo.jsx`, `DownloadSection.jsx`.
- `community/`:
  - `CommunityIntro.jsx` – Landing CTA for grid participation.
  - `CommunityParticles.jsx` – Animated background effect.
  - `PostCard.jsx` – Core post rendering, upvotes, comments, reporting controls.
  - `PostForm.jsx` – Post creation/edit form with validation.
- `admin/FileUploader.jsx` – Supabase Storage upload interface for tool binaries.
- `auth/AuthModal.jsx` – Sign-in/sign-up flow (email verification redirect to hub).
- `terminal/ClawNetTerminal.jsx` – In-app CLI with help command, ASCII art, auto-scroll.
- `effects/MatrixBackground.jsx`, `ParticleBackground.jsx`, `MatrixTransition.jsx`, `transitions/SystemShutdown.jsx` – Visual effects for transitions and ambience.
- `Loader.jsx` – Boot sequence animation displayed on initial load.
- `clawrank/`, `collaboration/`, `grid/`, `settings/` – Placeholders or supplementary components (verify before removal; keep for future expansions).

### Utilities (`src/utils/`)

- `fileStorage.js` – Supabase Storage helpers (upload/list/download/delete with signed URLs and validation).
- `security.js` – Input sanitization, validation utilities, CSP-aligned helpers.
- `seedSamplePosts.js` – Seeder for populating community posts during development/testing.

### Styles & Effects

- `styles/` – Additional CSS modules or theme files (populate as needed).
- `components/effects` & `components/transitions` – Encapsulate motion primitives for reusability.

## Supabase Migrations (`supabase/migrations/`)

- Timestamped SQL scripts creating tables:
  - `community_*` – Posts, comments, upvotes, flagged content.
  - `analytics` – Event tracking (views, downloads).
  - `service_requests` – Prospective client inquiries and status tracking.
  - `admin_actions` – Audit log of moderation/admin events.
  - `download_stats`, `banned_users` – Telemetry and access enforcement.
- Each migration paired with RLS policies enforcing `auth.uid()` checks.

## Documentation Suite (`docs/` + Root Guides)

- `docs/AUTH_MODULE.md` – Auth architecture, Supabase integration, API reference.
- `docs/COMMUNITY_GRID_MODULE.md` – Data flow, schema, RLS, testing for community hub.
- `docs/FILE_UPLOAD_MODULE.md` – Storage pipeline, validation, security considerations.
- Root guides for deployments, SEO, OAuth, security improvements, feature updates, email verification, GitHub setup.

## Tooling Artifacts (`tools/`)

- `clawview/` – Packaged desktop build (PyInstaller outputs, templates, static assets) for the ClawView visualization tool.
- `dist/` and `static/` subfolders within reflect compiled executables, SQLite databases (`clawview.db`), and front-end assets.

## Notes & Knowledge Base (`notes/`)

- `Developer_Notes.md` – Narrative on mission, services, governance, security posture, roadmap.
- `Technical_Notes.md` – Stack breakdown, Supabase usage, tooling, deployment, security measures, roadmap.
- `File_Structure.md` – This in-depth directory and artifact guide.

## Deployment & Infrastructure Assets

- `dist/index.html`, `dist/assets/*` – Production-ready output; ensure not edited manually.
- `public/robots.txt`, `public/sitemap.xml` – SEO and crawler directives.
- `netlify.toml` – Headers (CSP, referrer-policy), redirect rules; invoked during Netlify builds.
- `VERCEL_DEPLOYMENT.md` – Steps and caveats for Vercel deployment target.
- `DEPLOYMENT.md` – General production deployment process across hosts.

## Operational Considerations

- Environment variables (`.env`) supply Supabase URL/anon key; required for dev/build runtimes.
- `npm run lint`, `npm run build`, `npm run preview`, `npm run security:audit` – CI-ready scripts.
- Husky hooks (post-`npm install`) enforce pre-commit linting/formatting as configured.
- Tests currently stubbed (`npm run test`) to exit cleanly; future work includes real testing harness.
